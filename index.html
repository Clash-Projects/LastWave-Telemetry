Telemetry Ingress & API Reference

LastWave Telemetry is an ephemeral, in-memory stream monitoring service. Playback events are anonymously mapped to coarse regional centroids (~10km approximation) and held in a 60-second rolling sliding window. No personal data, listening histories, or raw IP addresses are ever written to disk or persistent storage.

Pipeline Architecture

01 / INGRESS

Coarse Resolution

Incoming IP is resolved to coarse city coordinates in RAM. Raw IP headers are discarded immediately after resolution.

02 / AGGREGATION

60s RAM Window

Thread-safe memory bucket aggregates active concurrent streams and increments regional velocity counters.

03 / EVICTION

Zero Persistence

No database writes or disk logging. Elapsed listener buckets and idle dynamic nodes expire automatically every 60 seconds.

GET /api/live-map

Retrieves the current real-time snapshot of active global listeners, active centroids, and chart metrics.

              POST
              /api/telemetry/ping
            

            
Anonymous heartbeat ping dispatched by LastWave client software when a track surpasses 30 seconds of playback. Rate limit: 10 requests / 60 seconds per IP.


            

              

                CURL REQUEST
                
              

              
curl -X POST https://telemetry.clashprojects.qd.je/api/telemetry/ping \
  -H "Content-Type: application/json" \
  -d '{"song_id":"trk_101","title":"Track Title","artist":"Artist Name","region_id":"in-bom"}'
