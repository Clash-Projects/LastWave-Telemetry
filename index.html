LastWave Live API & Ephemeral Architecture

LastWave Live is a lightweight, zero-tracking global telemetry engine for open-source music streaming. Playback heartbeats are aggregated into in-memory 60-second sliding windows with coarse mathematical location rounding (~10km centroid grid).

60-Second Volatile RAM Pipeline

100% IN-MEMORY
STAGE 01 IP ERASED

HTTP/2 Pulse Ingress

Remote IP and TCP socket headers erased immediately at the ingress gateway.

STAGE 02 ~10KM GRID

Concurrent RAM Bucket

Accumulates velocity into coarse geographic centroids for exactly 60 seconds.

STAGE 03 RAM EVICTED

Snapshot Swap & Eviction

Atomic memory pointer swaps cached JSON payload; elapsed bucket evicted from memory.

GET /api/live-map

Returns the full real-time snapshot of active global listeners, regional top charts, and rolling 24-hour stream counts.
